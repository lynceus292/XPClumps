# XPClumps

[![Platform](https://img.shields.io/badge/Platform-Paper%20%281.21%2B%29-9cf.svg)](https://papermc.io)
[![Java](https://img.shields.io/badge/Java-21%2B-orange.svg)](https://www.oracle.com/java/)
[![License](https://img.shields.io/badge/License-Open%20Source-brightgreen.svg)](#)

A lightweight, zero-config Paper plugin that groups experience orbs to reduce server lag. Built for PvP servers.

---

## Features

- **Zero configuration** — works immediately after install with sensible defaults
- **Groups XP orbs** within a 3-block radius, merging them into a single orb
- **Reduces entity count** and tick lag caused by scattered experience orbs
- **Lightweight** — a single event listener with minimal overhead

---

## Requirements

- Paper 1.21+
- Java 21

## Installation

1. Download the latest `xpclumps-*.jar` from [Releases](https://github.com/lynceus292/XPClumps/releases)
2. Place the jar in your server's `plugins/` folder
3. Restart or reload your server
4. Done — no configuration needed
